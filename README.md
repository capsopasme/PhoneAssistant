# 语音助手（PhoneAssistant）

给一加 Ace 5（SM8650 / LineageOS / Android 16 / KernelSU）用的语音助手：离线语音识别 + 大模型 tool calling（DeepSeek / 智谱 GLM / Gemini 三选一），完成闹钟、电话、导航、系统开关这类常见操作。

## 用法

1. 打开“语音助手”（桌面图标进入设置，顶部是“语音通话”入口；打开时不会自动弹出输入法）：
   - 在“大模型”里选一个（DeepSeek / 智谱 GLM / Gemini），填它的 API Key。只用选中的那一个，请求失败就直接报错，不会自动换别的模型。智谱默认 `glm-4.7-flash`（免费，Key 在 open.bigmodel.cn 申请，调用时关闭思考）；填 `glm-5.3-flash` / `glm-5.3-flashx` 时思考关不掉，会用最低的 `low` 强度。
   - 语音模型：小企鹅输入法里已经装了同款 SenseVoice 模型的话，点“从小企鹅复制”（需要 root），否则“下载”。装好后点“测试”确认 NPU 能跑。
   - 点“设为默认助理（root）”，再点“授予权限”。
2. 系统设置 → 系统 → 手势 → 系统导航 → 手势导航旁的齿轮 → 打开“滑动调用助理”。
3. 从屏幕左下角或右下角斜向上滑：底部弹出卡片，直接说话。说完停顿 0.7 秒自动结束，也可以点方块按钮手动结束，或者点输入框打字。

QuickBall 等应用可以启动 Intent 动作 `com.capsopasme.assistant.START` 唤起同一个界面。

## 语音通话：噜噜

像打电话一样和噜噜连续聊天（类似豆包的通话，但不是全双工）：你说完停一下，它想、然后用系统 TTS 读出回答，读完自动接着听你说。

- **噜噜是谁**：一只肥嘟嘟、圆滚滚的小猪，随叫随到的全能暖心生活搭子。情绪极度稳定——你发火、说重话、反复问同一件事，它都不急不恼不辩解；先接住你的感受再说话，也能答疑解惑（拿不准就上网查，不知道就直说，看病、法律、投资只讲常识并提醒找专业人士）。偶尔自称“噜噜”，可爱但不句句卖萌；每次只回一到三句话，把说话的机会留给你，想听它多讲时它也会多讲一点。聊到很难受、想伤害自己这类事时，它会稳稳陪着，也会温和地建议找信任的人或专业帮助。
- **样子**：通话页中间是一个圆球，外面一圈柔光：听你说话时随音量鼓起来、光变亮；思考时慢慢呼吸；说话时按说话的节奏轻轻跳动；关掉麦克风时变成静止的灰色。模式切换时大小和光都是平滑过渡的。只在看得见时动画，熄屏或切到后台不画。
- **能查东西**：需要最新消息（新闻、比分、行情…）或拿不准的事时，它会自己上网搜（手机直接请求 Bing 搜索页，Bing 不通时换 DuckDuckGo，不用 API Key），必要时打开最相关的网页读正文，再用自己的话讲给你；也能查天气。
- **不操作手机**：通话里不设闹钟、不打电话、不开关、不打开应用，“打开微信”这类本地快捷命令也不执行。要办事就说“切回助手”或退出通话，用卡片。
- **进入**：设置页顶部的“和噜噜通话”；卡片右上角的电话按钮；在卡片里叫它的名字（“噜噜”“叫噜噜来”“噜噜在吗”“我想跟噜噜聊聊天”，按读音比对，“路路”“鲁鲁”也认；但“给露露打电话”还是打电话），或说“进入通话模式”“陪我聊聊”“我想跟你聊聊天”“切到聊天模式”；长按桌面图标选“和噜噜通话”；QuickBall 等应用启动 Intent 动作 `com.capsopasme.assistant.CALL`。
- **退出**：说“退出通话”“挂了吧”“结束通话”“拜拜”“晚安”“先聊到这吧”；说“切回助手”会挂断并打开助手卡片。这些在手机上直接解析（不经过大模型）：前后的客气话和语气词（“那我们…吧”“好了拜拜啦”）会忽略，按读音比对，同音错字（“童话模式”“推出通话”）也认，两句连着说（“好的拜拜挂了”）也行；但必须整句就是这个意思，“给妈妈打电话”“别挂”“算了不说了”不会误触发。说法没覆盖到时，大模型听出你要结束也会自己挂断。
- **朗读**：用系统首选的 TTS 引擎，建议设为 [MOSS-TTS-Nano](https://github.com/capsopasme/MOSS-TTS-Nano)（系统设置 → 文字转语音 → 首选引擎）。大模型的回答按句子流式送过去，第一句生成完就开始读，不等整段写完。进入通话时会悄悄让 MOSS 把模型加载好，第一句回答不用等它冷启动。
- **轮流说话**：它说话时不开麦，不会听到自己；想打断就点中间的圆球，马上换你说。你说完停顿 0.8 秒（设置里可调）算一句；如果大模型还没开始回答你又接着说了，会把后半句接上重新问。一口气说超过十几秒也不会被截断。
- **熄屏照常工作**：通话由前台服务承载，锁屏、熄屏、切到别的应用都继续；按电源键亮屏，通话界面直接显示在锁屏上面（像来电界面）。返回键只是把界面收起来，通话在通知栏里，可以从那里回来、静音或挂断。
- **什么时候结束**：点挂断或说上面的退出语；很久没人说话（默认 3 分钟，可设为不自动挂断）；来电或闹钟响起；单次通话最长 1 小时。
- **声音**：默认像媒体一样从扬声器或耳机出声（MOSS 的高音质），手机麦克风听。底部可以切到听筒（贴耳朵时距离传感器自动灭屏）。设置里可以选“连着蓝牙耳机时用耳机麦克风”：走蓝牙通话通道，手机放口袋里也听得清，但朗读是通话音质。
- 通话期间音乐和视频会暂停，挂断后恢复。熄屏或离开通话界面时，轮到你说话会响一声短提示音（可关）。

## 噜噜的记忆（无感记忆）

像豆包那样，不用你下命令，噜噜会记得以前聊过的事（设置里可关，默认开）：

- **怎么记**：挂断后，这次通话的文字记录交给系统的 JobScheduler（有网才跑，失败自动退避重试，App 被关掉或手机重启也会补上，不常驻）。某一次通话如果整理不了（被大模型的内容审核拒绝、反复出错），只丢掉这一次，不会卡住后面的通话。用设置里选的那个大模型整理成两样东西：关于你的事（称呼、家人朋友和宠物、工作学习、作息喜好、最近的计划和烦心事，相对时间换成具体日期），和“这次聊了什么”的一两句摘要；再和已有记忆合并：新的加、变了的改、过时的删，超过 80 条时让模型合并精简（上限 120 条）。
- **怎么用**：接通时，记忆和最近 5 次通话的摘要放进噜噜的提示词，它会像老朋友一样自然地用上，不说“根据我的记忆”；更早的通话它需要时自己翻（`recall_memory`，按关键词查）。偶尔会主动关心你之前说过的事（“上次说的面试怎么样了？”），一次通话最多一次，你不接就不再提；让人难过的事你不提它不提。上一次通话还没整理完时（比如当时没网），新通话一开始就会整理，整理好后这次通话里就能用上。
- **说了就算**：“记住我下周三考试”当场记；“忘掉我家猫的事”当场删；“你都记得我什么”会如实说。
- **管理**：设置 → 噜噜（语音通话）→ 查看和管理：逐条删除记忆和通话摘要，或全部清空。
- **隐私**：只存在手机的应用私有目录（应用不参与备份）。整理时通话记录会再发给你选的大模型一次（聊天时本来就发给它）。不记密码、验证码、身份证号、银行卡号和详细门牌地址。关掉记忆后不再记录，还没整理的通话也会丢弃。

## 时停特效

设置 → 特效 → “时停特效”（默认关）。开启后，唤出助手卡片或开始通话时：一下重震、白闪，一个球从屏幕中心炸开（通话是从中间的圆球），球里颜色反相，球的边缘像透镜一样扭曲、红蓝分离；扫过全屏后整个屏幕定格、褪色、偏冷——时间像停住了，状态栏的时钟也停在那一刻。关闭卡片时，冻住的球向中心收拢，球外面直接就是正在运行的真实屏幕，收完就和原来的画面无缝接上，不会再看到窗口滑走；挂断通话时，通话页收缩回圆球，周围冻住的画面先解冻，再淡入到当前真实的屏幕（通话期间屏幕上可能已经变了），最后同样什么都不留。

- 做法：用 root 的 `screencap` 截一张当前屏幕，直接读进内存（不写文件），放进 GPU（硬件位图），用一个 AGSL 着色器画；动画结束就不再重绘，卡片关闭 / 通话结束就释放。通话为了挂断时的效果会留一张半分辨率的截图（约 3.5 MB）。
- 卡片开着时背后一直是定格的画面——本来唤出助手就会暂停外放的音乐和视频，正好对得上。
- 开麦不等特效：唤出就开始听，张嘴就能说。截屏约 0.1–0.3 秒，卡片会比不开特效时晚一点出现。
- 没有 root、或者当前应用禁止截屏（截出来是黑的）时，换成不反相的简化版（冲击波和变暗）。
- 只震动，不出声：外放的音效会被马上打开的麦克风收进去。画面风格是致敬，不用任何原作素材。
- 锁屏上、熄屏时不播；通话的界面先以透明窗口打开（截屏要看到它下面的画面），播完再变成不透明的（关掉特效时立刻变）。

## 能做的事

| 类别 | 工具 |
|---|---|
| 时间 | 设闹钟（可重复）、倒计时、打开闹钟列表、新建日程（打开日历编辑页确认） |
| 联系人 | 按姓名查号码、打电话（先确认）、写短信（打开编辑页由你点发送） |
| 出行/信息 | 导航（优先高德，其次百度，再其次 geo:）、打开应用、浏览器搜索、查天气（Open-Meteo，无需 Key） |
| 音乐 | 用留声机（Gramophone）按歌名 / 歌手 / 专辑播放，或随机播放全部（需要“音乐”权限才能模糊匹配曲库） |
| 媒体/声音 | 播放暂停上下首、各类音量、铃声/震动/静音、手电筒 |
| root 开关 | WiFi、蓝牙、移动数据、飞行模式、勿扰、定位、NFC、自动旋转、深色模式、护眼模式、极暗模式、省电模式、亮度、锁屏 |
| 查询 | 电量、充电、WiFi/蓝牙、铃声模式、勿扰、音量、剩余存储 |

“打开 xx”“倒计时 xx”这类短命令在手机上直接解析执行，不经过大模型（没网、没填 Key 也能用）：应用名按文字和拼音模糊匹配，同音错字（如“危信”→微信）也能认；拿不准、有多个相近应用、或是“打开蓝牙”这类系统开关时，再交给大模型。

“打开地图/计算器/阅读器/视频/浏览器/记事本/录音机/相机/音乐/相册”会打开固定的默认应用（CoMaps、Unitto、Anx Reader、mpv、Fennec、Moe Memos、Fossify 录音机、GrapheneOS 相机、留声机、Aves），大模型的打开应用、导航（CoMaps 搜索目的地）、网页搜索（Fennec）也用这些默认应用；没装时退回原来的方式。开发者选项、USB 调试、无线调试也能本地开关（root），打开无线调试会显示 IP 和端口（需要连着 WiFi）。

蓝牙、飞行模式、深色模式（深色主题 / 黑夜模式 / 暗夜模式 / 夜间模式…，“切换到浅色模式”就是关掉）、护眼模式（夜间灯光）、极暗模式同样本地执行：“关掉蓝牙”“把蓝牙给关了”“切换到深色模式”“护眼模式打开”“退出飞行模式”都能认，同音错字也行；已经是目标状态时会直接告诉你，不重复切换。本地说“打开飞行模式”不再弹确认（后面不需要联网）。

唤出助手时，如果有音乐或视频正在用扬声器外放，会先让它暂停（不理会音频焦点的播放器就临时静音），卡片关掉后自动恢复；戴耳机或连蓝牙时不处理。

大模型只回答、反问或者工具没执行成功时，卡片会自动重新开麦等你回话；8 秒没说话就自动关闭。

root 命令全部由代码按固定模板拼出，模型只能选开关名和开/关，不能传任意命令。关 WiFi、关移动数据、开飞行模式会先弹确认。

## 省电和内存

- 没有任何常驻服务、定时任务或唤醒词。卡片关掉后整个 App 就没有在运行的线程了。
- 只有语音通话期间才有前台服务和 WakeLock（熄屏也要能听、能说），挂断立刻全部释放；很久没人说话会自动挂断。通话时它说话时麦克风是关的，识别只在你说话时用 NPU 解码。
- 麦克风、识别会话、网络请求、工作线程都只在卡片显示期间存在；切到别的应用、锁屏都会立刻关掉卡片并释放。
- 识别在独立进程 `:asr` 里跑（NPU 初始化失败只会崩这个进程，界面会提示换 CPU 模型）。默认用完后保留模型：进程被系统冻结在后台缓存里，不占 CPU、不耗电，内存紧张时由系统回收，下次唤起不用重新加载。设置里可以改成每次用完立即释放。
- 听写有上限：7 秒没人说话自动结束，单次最长 25 秒；VAD 判断说完就停麦。
- 助手卡片的对话只保存在当前卡片里，关掉就没了。通话的文字记录在记忆开着时会留到整理完（见上面“噜噜的记忆”），整理完就删。API Key 和记忆都存在应用私有目录。
- 记忆整理是一次性的系统任务，整理完就结束；时停特效只在播放的不到一秒里用 GPU。

## 构建

原生库不在仓库里，CI 会从源码编 sherpa-onnx（QNN），跟小企鹅输入法 fork 用的是同一个脚本和版本（sherpa-onnx v1.13.8 + QNN 2.40）。

**GitHub Actions**：推到 `main` 或手动运行 “Build APK”，产物在 Actions 页面下载。`app/build.gradle.kts` 里的 `versionName` 还没有对应的 Release 时（比如改成 0.3.0），`main` 的构建会自动发布 Release `v0.3.0` 并附上 APK，说明取自 `.github/release-notes/v0.3.0.md`。仓库 Secrets 里配 `SIGN_KEY_BASE64` / `SIGN_KEY_ALIAS` / `SIGN_KEY_PWD`（可以直接复用 fcitx5-android 那套），否则每次用临时 debug 签名，后一个包装不上前一个。

**本地**：

```sh
export ANDROID_NDK=/path/to/ndk   # r27+
./voice/prepare-native.sh
./gradlew :app:assembleRelease
```

`com/k2fsa/sherpa/onnx/*.kt` 是 sherpa-onnx v1.13.8 的 Kotlin API 原样拷贝，JNI 按名字访问，升级 sherpa-onnx 时两边一起换。识别相关代码（`asr/`）改自 fcitx5-android 语音输入，保留 LGPL-2.1 头。
